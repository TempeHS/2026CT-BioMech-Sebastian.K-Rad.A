# Ultrasonic Glasses

We will be making glasses which utilise ultrasonsic sensors to help blind people navigate around in mainly indoor spaces. 
It uses LEDs and buzzers to notify the user when their surroundings change.

## Components List:
- 4 Ultrasonic Sensors
- 2 Buzzers
- 1 Green LED
- 1 Red LED
